## 新增

- **任务存储层（host）**：`<DSH_HOME>/super-ppts/tasks/` 按任务建目录——`task.json`
  详情（含事件流与产物引用）、`outline-vN.json` 大纲版本文件、`materials/` 素材；
  `index.json` 为**无损列表缓存**（缺失 / 损坏 / 条目少于磁盘时自动重建，损坏记录
  改名 `*.corrupt-*` 留底）。写入全部 tmp + rename 原子替换，零文件锁。
- **任务数据面（host）**：`tasks.list / get / create / update / delete / outline /
  confirmOutline / materialDelete / materialStatus` 九个 JSON 方法 +
  `POST /super-ppts/tasks/upload` 素材流式上传，全部沿用 `/super-ppts` 信任围栏与
  `{ok,value}` 信封；大纲确认做版本匹配校验（不符即 400，防串版本确认）。
- **`ppts_task` 状态桥工具**：Agent 侧上报阶段 / 提交大纲 / 登记产物 / 回报素材 /
  请求补充信息 / 记录失败 / **done 标记完成**（`completed` 的唯一入口，产物登记后
  收口生命周期，结果视图与轮询停止都依赖它）。**提交大纲后必须停下等待用户在任务
  面板确认**（确认门）。
- **侧边栏「演示文稿」任务面板**（重做，DSH 原生 main keyed 单列面板）：
  - **新建任务**：一句话主题 + 快速开始 + 交付形态卡片 + 可展开完整配置；模板选择器
    同时展示「插件内置」（4 套：经营复盘 / 产品发布 / 技术分享 / 教学课件）与
    「我的模板」，来源文本可辨，「不使用模板 / 跟随默认模板 / 具体模板」三态语义不混淆；
    素材本地多选上传（可删、有状态、单项失败不阻塞启动）。
  - **会话桥 v3**：点「开始制作」→ 任务先落盘 → Brief 写入会话输入框并**自动提交**，
    用户无需回到聊天窗口按回车；会话不可达时降级剪贴板并把任务置 `waiting-launch`
    （可恢复），绝不假装成功。
  - **大纲确认视图**（核心控制点）：页面卡片直接编辑（标题 / 目的 / 要点 / 类型 /
    顺序 / 增删 / 复制）+ 自然语言「让 Agent 修改」；任何修改都回到未确认态，
    **确认大纲并继续生成**是唯一主操作；Agent 并发提交新版本时自动重新载入而非串版本。
  - **生成进度视图**：六阶段时间线 + 当前阶段详情 + 事件流；四个恢复变体——
    启动恢复区（重试启动）、补充信息区（needs-input 问答）、错误恢复区（重试 /
    返回修改大纲 / 查看原因）、已取消只读详情；活跃任务 3 秒轮询，终态自动停止。
  - **结果视图**：产物条目（类型 / 状态 / 路径 + 复制路径）、丢失产物可发起重新生成、
    自然语言继续修改 + 四个快捷指令 chip。
  - **最近任务**：按「待处理 → 进行中 → 失败 → 已完成」分组，点击按状态恢复到
    对应视图；列表存在待办时顶部出现提示行。
- **内置模板元数据**：`src/builtin-templates.ts` 随包分发，`ppts_templates` 返回
  「内置 + 用户」两类来源，工具与面板共用同一口径。

## 变更

- 侧边栏「演示文稿」主面板由独立工作台改为任务面板（新建 / 最近 / 任务详情三态）；
  草稿桥 v2（`setDraft`）升级为会话桥 v3（`setDraft` + `submit()`），剪贴板保留为
  最后兜底；模板下拉升级为模板选择器。
- 面板视觉统一宿主 `--dsw-alias-*` token；无插件自有侧边栏 / 右侧栏 / 全屏容器 /
  视口单位 / 固定定位——宽度、滚动、主题全部归宿主。

## 修复

（开发期审查与变异测试发现，随本版本一并落地）

- 索引缓存按 `updatedAt` 裁剪会把「等待确认最久」的任务挤出列表且永久不可见——
  改为无损缓存，磁盘任务目录为真源。
- 幽灵索引条目（缓存有、磁盘无）在加载时剔除并持久化；损坏任务改名留底不再阻塞列表。
- `tasks.create` 强制要求 `workspace`（空串兜底会产生无法筛选、无法恢复的任务）。
- 任务路由补 403 / 405 围栏守卫与状态白名单；素材上传失败回滚孤儿文件。
- （发布提交后最终集成审查，详见 plan 2b「实现后审查修订」R1-R5）详情视图组件类型
  每渲染重建导致轮询每 3s remount 丢大纲未保存编辑——壳层按 `(sub|taskId)` 经
  `ensureDetailView` 缓存组件类型，三视图改为 props 优先、工厂 opts 兜底读 live
  task/回调；`completed` 全链路不可达（无任何动作可置该态）——host 增补 `ppts_task`
  的 `done` 动作收口；结果摘要措辞按交付形态分流（PPTX / HTML 在线演示）；轮询遇
  not-found（任务已删）即停不空转。

## 删除

- 旧独立工作台组件 `makeWorkbenchComponent` 及其专属样式与 v2 草稿桥（能力已由
  任务面板五视图 + 会话桥 v3 承接）。

## 兼容性与升级说明

- 无破坏性变更：设置页「演示文稿」（模板管理 + 偏好）与既有 `ppts_check` /
  `ppts_render` / `ppts_templates` 工具、技能线、模板库存储全部不动。
- 任务数据为全新目录，升级无需迁移；回滚到 1.3.x 仅丢失面板入口，`tasks/` 数据可留。
- 宿主兼容：0.1.5+ 获得完整面板；≤0.1.4 面板注册静默跳过（设置页不受影响）；
  无输入框注册面的宿主自动降级剪贴板桥（任务置 `waiting-launch` 可恢复）。
- **已知边界**：
  1. 产物无下载 / 预览路由（数据面按规格只存引用）——结果页操作为「复制路径」，
      HTML 演示的打开需按路径手动处理；下载路由在后续版本评估。
  2. 旧工作台遗留的少量双语字典键成为孤儿（零行为影响，待后续清理）。
