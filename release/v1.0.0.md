## 新增

**双交付形态架构**

- 一个插件交付两种演示形态：可编辑 PPTX 与单文件 HTML 在线演示，统一「设计导演」工作流与渲染验收闭环。

**PPTX 交付线（skills/ppts-pptx）**

- 引擎：PyPI 公共库 `pptx-designer`。
- 七步设计导演工作流：Brief 契约 → 视觉预检 → 页面规划 → 视觉方向锁定 → 生成路径 → 构建检视循环 → 用户确认。
- 三种生成模式：Build Mode（逐元素精确控制，生成脚本为唯一事实源）/ FreeStyle（快路径）/ VI Build（企业模板合规，`extract_design_dna()` 模板分析）。
- PPTX → PDF → PNG 渲染验收闭环，交付级任务不得跳过；渲染链不可用时按降级协议处理。
- 4 篇 references：API 契约（content-and-api）、设计原则（design-principles）、领域范式（domain-paradigms）、验收与降级协议（review-and-delivery）。

**HTML 交付线（skills/ppts-html）**

- 统一入口 + 8 种形态：slide-deck（翻页演示）、flowchart（流程原理图）、protocol-viz（协议可视化）、arch-diagram（工程架构图）、card-theater（3D 卡片剧场）、scholar-notes（手写笔记）、video-shots（电影化分镜）、phone-ui（手机系统 UI）。
- 全线硬性红线：单文件自包含、图标内联 SVG（禁 emoji 作图标、禁真实商标）、禁外部 CSS/JS 框架、1920×1080 舞台自适应、动效有入有出、重要信息静帧可读。
- 共享设计 token（skills/shared/design-tokens.md：字体栈 / 字级 / 对比度 / 动效时长 / 图标规范）。
- arch-diagram 工程化：6 类 JSON Schema + 6 个渲染器（architecture / workflow / sequence / dataflow / lifecycle + 共享 geometry / validator / cli）+ golden / geometry / layout-rules / degraded 测试，支持导出 PNG / SVG / GIF / WebM。
- video-shots：双角色立绘体系（anan 15 态 + shery 20 态）+ `shot.js` 无头截图质检（Node ≥ 18）。

**原生工具（host 侧）**

- `ppts_check`：环境自检（Python ≥ 3.10 / pptx-designer / soffice + pdftoppm 渲染链）。
- `ppts_render`：PPTX → PDF → PNG 渲染验收（跨平台 soffice 探测 + PATH 外兜底路径）。

**Host 壳（src/ → lib/）**

- 预设安装（~/.dsh/.agent-presets/super-ppts/，幂等）、能力通告（systemPrompt section，order 206）、原生工具注册；零 npm 依赖、无本地服务、外部进程一律 execFile 参数数组。
- client 侧手写自注册 no-op 壳（`window.__ModuleLoader__.load` 形态，规避裸 ESM 不注册坑）。

**编译桥（compiler/build_pptx.py）**

- `--check` 环境自检 / `--ensure-deps` 自动装依赖（pip --user 优先，PEP 668 受管解释器降级专属 venv ~/.dsh/venvs/dsh-super-ppts）/ `--run` Build Mode 脚本（`--expect` 产物 glob 校验）/ `--quick` FreeStyle 一句话生成。

**Agent 预设（presets/）**

- 「演示文稿专家」预设：双交付形态路由 persona + 环境与路径约定。

**工程与分发**

- `scripts/sync-to-dsh-plugins.mjs`：dsh-plugins 真源仓镜像同步（`--check` 对账）。
- `demos/` 实机样例（3 个 HTML + PPTX 样例 + 本地重放脚本）与 `docs/screenshots/` 展示图。
