## 新增

### 设置页菜单项「演示文稿」（Web GUI）

- 插件首次提供 client 侧扩展（`lib/client.js`，手写 `__ModuleLoader__` 自注册形态）：
  经 `ctx.slots` 注册 `settings.section`（导航 id `super-ppts`，默认顺序 20），
  设置页出现「演示文稿 / Presentations」菜单项。
- **模板库管理**：
  - 上传 .pptx 模板（原始字节流式 POST `/super-ppts/upload`，首块 PK 魔数校验、
    大小限额即断，默认 100 MB，可经 `cordis.yml` patch `uploadLimitMb` 调整）；
  - 上传时命名 + 可选描述；名称唯一（重名冲突 409 拒绝，避免「按名调用」歧义）；
  - 重命名 / 改描述（只动清单不动文件）、设为默认 / 取消默认、删除（清单 + 磁盘一致清理）。
- **生成偏好**（与模板库一起打包提供给 Agent）：
  - 默认交付形态：每次询问 / 可编辑 PPTX / HTML 演示；
  - 渲染验收策略：仅交付级验收（默认）/ 每轮都验收 / 关闭；
  - 输出目录（留空 = 会话工作目录，支持 `~` 前缀）；
  - 风格偏好备注（自由文本，作为 Agent 的全局审美基线）。
- 双语界面（zh/en，走 `ctx.locale`，命名空间 `superPpts`）。

### 数据与安全面（host 侧）

- 存储层 `src/templates.ts`：模板与清单落盘 `~/.dsh/super-ppts/`
  （`templates/<id>.pptx` + `registry.json`）；清单一律原子写（tmp + rename）；
  模板 id 与文件名解耦（重命名不动文件）；坏 JSON 回落默认，绝不阻断插件加载。
- HTTP 面 `src/routes.ts`：`/super-ppts/api/<method>`（templates.list /
  templates.rename / templates.delete / templates.setDefault / prefs.update）
  + `/super-ppts/upload`；信任围栏同位镜像生态约定（loopback Host 或
  trustedHosts 放行，跨站浏览器标记拒绝）；响应信封 `{ok,value}/{ok,error}`。
- 零 npm 依赖红线保持：client 与 host 全部 node 内置 + React（宿主提供）。

### Agent 侧

- 新原生工具 `ppts_templates`：模板库 + 生成偏好的唯一读取面。
  `action=list` 全量（名称/id/绝对路径/描述/是否默认 + 偏好），
  `action=detail` 按 id 或名称取单条（不区分大小写精确匹配）。
- 能力通告更新：用户说「按模板 X 制作 / 用我的模板」→ agent 先查
  `ppts_templates` 拿路径与偏好，再按技能线 VI Build 模板化路径生成。
- `skills/ppts-pptx/SKILL.md`：VI Build 路径补「用户模板库优先」分支；
  库为空时引导用户到设置页上传。

## 兼容性与升级说明

- 全部新增面为加法：既有工具（`ppts_check` / `ppts_render`）、技能线、
  预设行为不变；不升级不影响既有工作流。
- 升级方式：KCoder 插件管理检测新版本后手动更新，或
  `dsh plugin --profile web update dsh-super-ppts`。
- 升级后需**重启 / 重载 web profile**（host 路由随插件进程装载；设置页
  菜单项随页面刷新加载 client bundle）。
- 首次使用：设置页「演示文稿」→ 上传 .pptx → 命名 → 对话里
  「按模板 <名称> 制作」。

- `node scripts/smoke-plugin.mjs`：27 项全通过（含**降级安全**：ctx.slots
