# v1.4.4（2026-09-27）

## 1. 版本信息

- **版本号**：1.4.4（patch）
- **日期**：2026-09-27
- **tag**：`v1.4.4`
- **主题**：设置页菜单式版式——对齐 DSH 原生 SideCardSection 配方的分组卡片与菜单式设置行
- **发布渠道**：npm + GitHub

## 2. 新增

- 设置页「演示文稿」整页版式重做为**菜单式布局**（对齐 dsh-coding-sidebar
  SideCardSection 配方 / DSH 原生 group recipe）：
  - 分组卡片：l2 细线边框、16px 圆角、layer-3 填充，三个分组——
    **模板管理**（模板 CRUD 菜单行，头部带数量徽标）/ **上传模板**（表单菜单行）/
    **偏好设置**（偏好菜单行）；
  - 菜单式设置行：标题/描述在左、控件在右、细分隔线（`sp-set-row` 系列）；
  - 控件全套 DSH 原生风格：开关（`sp-set-switch`，track+thumb、选中态走
    `--dsw-alias-button-primary-fill`）、按钮（主/次/危险三态）、输入框/下拉/
    文本域（聚焦 outline 环）、消息条（成功/错误语义色）；
  - 配色全部走 `--dsw-alias-*` 令牌并带硬编码兜底，**跟随宿主明暗主题**。

## 3. 变更

- 模板列表行由「名称+徽标 / 描述 / 元信息」堆叠式改为单行菜单式
  （标题行内嵌默认徽标，描述·大小·日期合并为副标题行，操作按钮恒在右侧）；
  行内编辑表单同样改为菜单行口径。
- 上传表单与偏好表单由 `sp-card` 卡片改为 `sp-set-group` 分组卡片，
  字段 label 改为行标题 + 行描述结构；操作按钮由 `Btn` 辅助组件改为
  显式 `sp-set-btn` 按钮，busy 态禁用逻辑不变。
- `src/client/index.ts` 功能面注释同步新版式描述（类型参考，不参与构建）。

## 4. 修复

- 无（本版为纯版式/样式改造，数据面与交互逻辑不变）。

## 5. 删除

- 设置页改版后成为死码的旧样式规则随版清理（`lib/client.js` CSS 内已无
  JSX 引用）：`.sp-card`（含 h3）/ `.sp-tpl`（含 first-of-type）/
  `.sp-tpl-meta` / `.sp-badge` / `.sp-edit`。
- 任务面板仍在用的 `sp-field` / `sp-row` / `sp-actions` / `sp-grid` /
  `sp-hint` / `sp-input` / `sp-tpl-name` / `sp-tpl-desc` 等类不受影响，原样保留。

## 6. 兼容性与升级说明

- 无接口契约变更：host 侧工具、`/super-ppts/api/*` 数据面、任务面板、
  会话桥均原样；`peerDependencies` 范围不动（`>=0.1.0-rc.5 <0.2.0`）。
- 仅 `lib/client.js`（设置页壳）视觉层改动，直接从 1.4.3 升级即可，
  无迁移步骤。

  设置页/任务面板回归断言）；
- `npm pack --dry-run` 发布面核对（lib/skills/compiler/demos/docs/release
  + cordis.patch.yml 齐全）。
