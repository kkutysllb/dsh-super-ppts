## 修复

- **模板库数据根跟随宿主 home**（重要）：存储根由写死 `~/.dsh/super-ppts` 改为按
  宿主规则解析（`$DSH_HOME` → `~/.dsh`）。KCoder 桌面端（`DSH_HOME=~/.kcoder`）
  在 1.3.0 里读不到历史模板（空库假象）；本版读取时自动把旧根数据迁移进当前根，
  并把清单里的旧绝对 file 路径按模板 id 重锚自愈——升级后历史模板直接可见，无需
  重新上传。
- 旧预设清理同样跟随 `$DSH_HOME`（`$DSH_HOME/.agent-presets/super-ppts` 与历史
  写死的 `~/.dsh/...` 两处候选位都清，幂等）。
- 冒烟测试增加 `$DSH_HOME` 环境隔离——测试永不触碰真实用户数据。

## 新增

- **工作台视觉重做**：不再复用设置页弹窗宽度约束（修复主面板内容左侧截断）；
  图标徽章头部 + 三段面板结构（快速开始 / Brief / 模板速览）、圆角卡片、
  hover/焦点态，全走宿主 `--dsw-alias-*` token，深浅色自适应。
- **内置提示词模板**：8 条快速开始（季度汇报 / 项目复盘 / 产品发布 / 教学课件 /
  技术分享 / 读书笔记 / 周报总结 / 数据看板），点击填入主题，内容可自由修改。
- 模板速览空态改为图标引导式空态；卡片 hover 高亮。
- 文案对齐新行为：按钮「放入对话输入框」，说明与回执文案均为草稿语义。

## 兼容性与升级说明

- 自 1.3.0 直接升级无破坏性变更；模板库自动迁移，无需手动操作。
- 修复后首次加载会把 `~/.dsh/super-ppts`（若存在）整体搬进
  `$DSH_HOME/super-ppts`，旧根保持原样不删除。

## 验证

- `npm run build && npm run smoke` 全绿：新增数据根解析（默认 / `$DSH_HOME` 覆盖）、
  旧存储根迁移、清单 file 重锚自愈四条断言；既有断言全数通过。
- 实机验证：KCoder 桌面端重载后「科室月分析」模板在设置页与模板速览可见。
