# v1.4.6（2026-10-04）

## 1. 版本信息

- **版本号**：1.4.6（patch）
- **日期**：2026-10-04
- **tag**：`v1.4.6`
- **主题**：peer 兼容门上界修正（`<0.2.0` → `<1.0.0`）——dsh `0.2.1-alpha.1` 适配
- **发布渠道**：npm + GitHub

## 2. 新增

- 无（本版为兼容门声明修正批）。

## 3. 变更

- **修复：dsh `0.2.1-alpha.1` 下插件被兼容门静默禁用**：
  - **现象**：升级到上游 `dsh-v0.2.1-alpha.1`（2026-10-03 prerelease）后插件不再加载，
    只在宿主 stderr 留一行 `disabling profile plugin …`，界面无提示。
  - **根因**：5 条 `peerDependencies` 上界 `<0.2.0` 对运行时 `0.2.1-alpha.1`
    求值为 **false**。该范围定义于 0.1.7 世代，仅在 `0.2.0-rc.*` 下侥幸成立
    （semver 里 `0.2.0-rc.2 < 0.2.0`），上游跨过 `0.2.0` 边界即失配。
    宿主检查器只读 `@deepseek-ai/dsh` 与 `@deepseek-ai/dsh-*` 前缀的 peer，
    按 `semver.satisfies(..., { includePrerelease: true })` 评估
    （`packages/boot/app-boot/src/plugin-compatibility.ts`）。
  - **修复**：5 条 peer 上界统一改为 **`<1.0.0`**；`peerDependenciesMeta` 保持
    **全部 optional**（防 pnpm 把整棵引擎树拉进用户 profile，硬要求不动）。
- 该范围**放宽**是向后兼容的：旧范围覆盖的 `0.1.0-rc.5` → `0.2.0-rc.2` 仍在新范围内，
  现网 KCoder（0.2.0-rc.2）行为不变。

## 4. 兼容性与升级

- 纯声明层改动：仅 `package.json` 的 5 条 peer 范围 + 版本号；
  `lib/**`、技能编排、双通道 manifest（`dsh`/`qilin`）、槽位注册全部不变；
- 升级即替换包体，无需迁移。

## 5. 验证

- `node scripts/smoke-plugin.mjs` **全绿**（含「每个 dsh peer 范围含 prerelease 比较器」
  与「dsh peer 全部 optional」两条契约断言、版本号对账）；
- 语义实测（semver 7.8.5，`includePrerelease: true`）：
  `0.2.1-alpha.1` 对 `<0.2.0` = **false**，对 `<1.0.0` = **true**。
