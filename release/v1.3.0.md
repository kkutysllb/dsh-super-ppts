## 移除（破坏性）

- 移除插件自造的「演示文稿专家」Agent 预设（`presets/` 目录与
  `~/.dsh/.agent-presets/super-ppts/` 安装逻辑）。DSH 0.1.16 起 agent-presets
  按 `agent.cordis.yml` 组合挂载，该模式已失效。
- 升级后插件 apply 时自动幂等清理旧预设目录（best-effort，失败不影响其余功能）。
- 路由引导由 systemPrompt 能力通告（SUPER_PPTS_GUIDANCE）承担，无需任何操作。

## 新增

- 侧边栏「演示文稿」工作台（新会话与工作区之间的原生按钮 → main keyed 面板）：
  - **工作区选择行**：读宿主全局标准 hook `useWorkspaces`，显示工作区标题与路径，
    默认「跟随当前工作区」（与「新会话」同一继承规则）；旧宿主缺失 hook 时整行隐藏。
  - Brief Hero（主题一句话 + 交付形态 + 模板选择）+ 模板速览卡片（只读 + 「使用」）。
  - 加载 / 空态 / 错误态 + 重试，视觉走 `--dsw-alias-*` 宿主 token。
- **正式草稿桥 v2**：会话落点（同工作区直用当前会话；跨工作区/无会话经
  `uiWorkspace.openWorkspace` 复用该工作区空白会话或新建，并自动切回对话视图）
  → `conversation.input.for(actx).setDraft(text)` 填入当前会话输入框，
  **用户确认后回车发送**；任一步不可达自动降级剪贴板（v1 行为保留为 fallback）。
- 设置页「演示文稿」菜单项、模板上传/管理、偏好编辑**保持不变**。

## 变更

- 依赖声明：`dsh.client.inject` 补 `@deepseek-ai/dsh-client-ui-conversation`、
  `@deepseek-ai/dsh-client-ui-workspace`；client inject 补 `uiWorkspace`、`workspaces`。
- 工作台主按钮语义由「复制提示词」改为「放入输入框（用户确认后发送）」；
  剪贴板路径保留为降级显示。

## 兼容性与升级说明

- 目标宿主 DSH 0.1.16-alpha.1（0.1.6-alpha.1 构建契约一致）；旧宿主自动降级：
  无输入框直填时走剪贴板路径，无工作区 hook 时隐藏工作区行。
- 旧「演示文稿专家」预设切换入口随宿主升级自然消失，无需迁移；
  旧目录 `~/.dsh/.agent-presets/super-ppts/` 由插件启动时清理。

## 验证

- `npm run build && npm run smoke` 全绿：预设清理断言、草稿桥/工作区同构哨兵、
  工作台状态完备断言、真 cordis + 真 ToolRuntime 插件树加载闸门。
- 手动验收：同工作区发起 / 跨工作区发起 / 无会话冷启动三条路径草稿均落输入框，
  回车后 Agent 按技能线执行并交付。
