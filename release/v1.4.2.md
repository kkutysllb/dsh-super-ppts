## 新增

- **QiLin（麒麟）双通道适配**：manifest 同时声明 `qilin` 与 `dsh` 两个通道的
  `bundle.patch` / `client`——QiLin（dsh 0.1.6-alpha.2 合并后）的插件管理器只认
  原生键 `qilin.bundle.patch`（缺失报「没有声明组合包」），DSH 宿主仍读 `dsh.*`；
  两通道指向同一份 `cordis.patch.yml` 与 client 交付物，行为完全一致。
- **编译链 venv 落位跟随宿主家目录**：`compiler/build_pptx.py` 的专属虚拟环境
  解析改为 `QILIN_HOME` → `DSH_HOME` → `~/.dsh`（与插件运行时 `lib/templates.js`
  同口径），QiLin 启动器注入的部署位直接生效；都缺席回退 `~/.dsh`（历史行为，
  兼容裸 python 直跑）。
- **README 新增「麒麟（QiLin）引擎安装」**：`qilin plugin --profile qilin add`
  安装方式、profile 私有 node_modules 的注意事项（共享安装保留区会
  `failed to import`）、引擎版本要求（运行 3.0.0+ / 插件管理 3.0.2+）。

## 兼容性与升级说明

- 自 1.4.1 直接升级无破坏性变更：DSH / KCoder 宿主的取值路径不变
  （`DSH_HOME` 照旧生效），仅新增 `QILIN_HOME` 更高优先级。
- 包含 1.4.1 全部内容（面板样式注入三通道加固、品牌色选中态、面板滚动接管、
  内置模板真实 SVG 缩略图）。
- QiLin 引擎要求：运行需带 dsh 兼容层的 QiLin 3.0.0+；插件管理（设置页展示 /
  启停）要求 3.0.2+。
