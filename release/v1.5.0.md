## 2. 新增

- **参考图重建线（第三交付线）**：新技能线 `skills/ppts-rebuild`——用户给截图/参考图说「复刻成可编辑 PPT」，走元素盘点 → Build Mode 原生重建 → 渲染并排对比 → 逐元素对账（最多三轮修订）；整页贴图为底线违例。能力通告升级为三交付线，触发词含「复刻这张图」。
- **结构机检 + 内容 QA**（`validate_pptx.py`）：zip/CRC 容器完整性、必要部件、rels 引用闭包（「LibreOffice 能开、PowerPoint 报损坏」的主因）、占位符内容 QA（lorem/TODO/待补充…）；接入验收循环——FAIL 必须先修才能进视觉门；`--json` / `--selftest`。
- **页间切换写入**（`add_transitions.py`）：PML 1st edition fade/push/wipe/cut + 秒级自动翻页 + 页码选择器，幂等重跑覆盖；混合交付新增 Phase 0（显式声明才触发，同 GIF 嵌入纪律）。
- **演讲备注写入**（`add_speaker_notes.py`）：JSON/命令行双载荷写 notes 页，写入后自动跑结构校验；Brief 契约加「是否需要演讲备注」，交付包含逐页备注与讲稿语义。
- **模板版式网格预览**（`template_thumbnails.py`）：用户模板逐页渲成带页码小图 + 可选 Pillow 网格总览；「按模板制作」前 agent 必须逐页看过再选版式（不再凭首页缩略图猜）。
- **原生图表纪律与图片策略**（技能文档）：数据页决策树（原生 chart 组件 → svg_chart → 自绘，「能原生不落图」）+ 素材 CSV/Excel 数据管线 + 图表防坑清单；图片三级通道（用户素材 → 引擎/生图 → CC 检索+署名清单 → 自绘），验收表含「图片来源合规」。
- **PDF 双登记交付闭环**：交付级任务 `.pptx` + `.pdf` 成对交付，任务流内 ppts_task artifact 双登记；验收循环改「只重渲改动页」。
- **生成画像**：`ppts_templates` 新增 `action=history`——聚合任务库（近 30 条）返回常用交付形态/模板分布、风格取值、大纲返工率、最近主题；Brief 确认时可作默认值提案（历史偏好让位于用户当下要求）。
- **回归评测集**：`docs/benchmarks/regression-briefs.md`——10 条固定 brief + 三维 0-2 分细则（内容保真/视觉/流程纪律），发版前自评协议。
- **内置模板扩容 16 方向 + 真缩略图 + 完整样例预览**：
  - 方向 4 → **16**（对齐同生态最大模板面竞品）：新增政务汇报、电商大促复盘、可持续 ESG、工程项目汇报（此前一批已增融资路演、工作周报、市场营销、深色数据大屏、极简主义、学术答辩、杂志编辑风、医疗健康）；
  - 缩略图升级为**真 deck 首页截图**：每个方向随包分发单页样例 deck（python-pptx 逐元素复刻设计稿）+ soffice 渲染截图，经新路由 `GET /super-ppts/templates/builtin-thumb/<id>` 下发；手绘 SVG 降级为 404 兜底示意，再兜底 accent 色块；
  - **点开看完整样例**：样例 deck 扩为 4 页（封面 + 参数化内容/数据/结尾），模板卡片新增「预览样例」→ 面板内翻页浏览器（`makeSampleView`：返回 / 页码 / 前后翻页），图源 `?page=N`；metadata 新增 `samplePages`。
- **HTML 线导出**（`export_html.js`）：零依赖直驱 Chrome headless，16:9 单页零边距 PDF + 视口 PNG（静态快照语义，动效页指定时刻帧仍用 shot.js）。
- **CJK 排版专项**（`skills/shared/design-tokens.md`）：中文禁斜体、字重三档、中西文混排呼吸、避头尾、标点挤压、数字等宽——双线红线，各形态可加码不可突破。
- **分发面**：`docs/distribution.md`（awesome-dsh-plugins / dsh.pub 提交文案与核查记录）。

## 3. 变更

- **JSON 操作面 content-type 契约收紧**（安全 M3 的行为面）：`/super-ppts/api/*` 现要求 `application/json`（缺失/不符 → 415）——第三方直调 curl 必须带头；client 内置调用零改动。
- **大纲确认视图 UI 重排**（实机反馈「裸表单与其他视图不一致」）：输入/下拉/要点域统一 token 盒形、页操作钮幽灵化、「确认大纲」主色 CTA、「让 Agent 修改」修复为描边钮（旧规则误渲染成虚线容器）、页码文案「第 {n} 页」；样式哨兵清单补收大纲视图全部契约类（裸奔无报警的根因）。
- 能力通告：双交付形态 → 三交付线；模板指引加「先跑版式网格预览」；任务上报明确「PPTX 与 PDF 各登记一条」。
- README：三交付线口径、目录结构、工具表（ppts_templates history）。

## 4. 修复

- **host 安全加固**（`security-audit-host.md` M1–M5 全修复，0 Critical/High，5 Medium 清零）：
  - M1 清单投毒 → 任意文件删除：`deleteTemplate` 只清 id 白名单内重算的规范位路径；`reanchorRecord` 丢弃白名单外 id、域外 file 读取即重锚；
  - M2 `prefs.outputDir` 落盘前 ~ 展开 + resolve 规范化（消费侧拿到消歧绝对路径）；
  - M3 CSRF 双层纵深：写路由 Origin 同源粗校验（异源 http(s) → 403）+ JSON 操作面 content-type 契约（表单伪造不可达）；
  - M4 名称/描述/styleNotes 控制字符消毒（多行文本保留 \t\n、剔除 \r）；
  - M5 `ppts_render` outDir 必须是已存在目录（起子进程前判定）。
- **shot.js 存量 ESM 崩溃**：`type:module` 仓库下 require 直接 ReferenceError（技能文档一直推荐、实际一跑就挂）；与 export_html.js 一并转 ESM + 模块加载回归断言。
- 大纲页码「第 01」残缺 → 「第 01 页」（outlinePageNoFmt）。
- 内置模板生成器背景矩形缺失导致深色方向渲染成白底白字（首版真缩略图全坏，重建修复）。

## 6. 兼容性与升级说明

- **行为契约变化（唯一）**：`/super-ppts/api/*` 要求 `content-type: application/json`，否则 415。内置 client 零影响；写脚本的第三方需要适配。
- `peerDependencies` 不动（`>=0.1.0-rc.5 <1.0.0`，v1.4.6 起的上界覆盖 0.1.x/0.2.x）。
- 面板/设置页数据结构向后兼容；新增 `samplePages` 字段为增量（旧 client 忽略）。
- 从 1.4.5/1.4.6 直接升级，无迁移步骤。
