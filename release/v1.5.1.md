# v1.5.1（2026-10-09）

## 1. 版本信息

- **版本号**：1.5.1（patch）
- **日期**：2026-10-09
- **tag**：`v1.5.1`
- **主题**：DSH `0.2.1-alpha.2` 适配（信任来源迁移）+ 模板规范链路补齐（约束拆条 / 规范提取 / 排版机检）+ 面板宽度与控件归一 + 死代码清理
- **发布渠道**：npm + GitHub

## 2. 新增

- **`skills/ppts-pptx/scripts/template_spec.py`**——模板规范提取。读出模板**文字里
  写明**的分层字号/字体/行距/颜色（`levelRules`），以及模板实际用到的字体/字号
  分布（`observed`）。作者按 px 标注时按 **1px = 0.75pt** 折算，同时保留
  `sizeAsWritten` 供对账。只用标准库（`zipfile` + 正则），不依赖 `python-pptx`，
  因此在缺 `pptx_designer` 的安装形态下也可运行。
- **`skills/ppts-pptx/scripts/check_typography.py`**——排版合规机检。把「最小字号 /
  字体白名单 / 配色数」变成可判定的 FAIL/WARN 门，与 `validate_pptx.py` 同款退出码
  （0=PASS，1=有 FAIL）。支持 `--spec template-spec.json` 由模板规范自动推导字号下限。
- **`ppts_templates` 输出新增 `constraints` 字段**（模板条目级）：把「模板描述 +
  全局风格备注」按中文标点拆成**逐条硬性约束**，使 Agent 能逐条落实并自检，而不是
  把整段散文当背景介绍。
- **`src/routes.ts` 新增 `resolveTrustedHosts()`**（导出）——集中解析信任来源。

## 3. 变更

- **面板宽度回归限宽居中**（实机反馈：上一版吃满宿主列后过宽）：`.sp-panels` 与
  `.sp-set` 统一 `width:100%; max-width:960px; margin:0 auto`，对齐 dsh-animations
  的 `.anim-content` 口径。窄列下仍 `width:100%` 自适应，`container-type` 与
  `@container` 重排机制不变。注：v1.4.5 曾反向解除 1.4.1 的限宽，本版按实机对比
  重新收紧。
- **控件度量归一**：交互控件统一到 **13px / 21px 行高** 一档，正文保持 14px。
  `.sp-btn` 28px→32px 高、8px→16px 圆角、12px→13px 字；`.sp-quick-chip` / `.sp-tab` /
  `.sp-tpl-filter .sp-btn` 的 14px→13px；`.sp-btn-primary` padding `0 14px`→`0 12px`。
  卡片度量对齐 dsh-animations `.anim-card`：`.sp-format-card` / `.sp-tpl-card`
  padding `12px 14px`→`14px 16px`、gap `4px`→`6px`；`.sp-format-card-active` 选中描边
  由 `border-l2`（与 hover 同色、选中不可辨）改为 `--dsw-alias-border-l4`。
- **`ppts_templates` 的 `detail` 现在返回 `prefs`**：技能文案一直声明 `action=detail`
  可取「模板路径**与偏好**」，但实现只返回了 `template`——照技能行事的 Agent 因此
  拿不到 `styleNotes` 里的全局风格约束。现已补上，并同步工具 description。
- **技能线接线**：`SKILL.md` §5 模板任务改为三步（**① 读规范——不要只出图 →
  ② 看版式 → ③ VI Build**），明确 `constraints` / `levelRules` 是验收项而非背景介绍；
  §6 构建循环在结构机检后插入**排版机检**为必经门；命令面补两个新脚本。
  `references/review-and-delivery.md` 的「机检层」由单脚本扩为结构 + 排版双门。

## 4. 修复

- **dsh `0.2.1-alpha.2` 下 LAN 部署 `/super-ppts/*` 全部 403**（症状：非 loopback
  访问时设置页模板管理与任务桥静默失效，界面无提示）。根因：上游移除了
  `webRuntime` 服务，改用 `webStartup` 承载 `--trusted-host` 权威
  （见上游 `docs/upgrade-guide/v0.2.1-alpha.1/web-listener-trust-config/guide.md`），
  而插件仍在软探测 `ctx.get('webRuntime')`，取不到即回落 `[]`，围栏收窄为纯
  loopback。修后 `resolveTrustedHosts()` 优先读 `webStartup`、回退 `webRuntime`
  （向后兼容 alpha.1 及更早），并额外放行监听器自身绑定地址，对齐 dsh 自身围栏
  `api-request-trust.ts` 的 `isBindAddressAuthority`。**不声明 `inject`**——声明了
  反而会等待永不挂载的服务而卡住启动。
- **客户端 `formatSize` 行为分叉**：同名函数在同一个作用域声明了两次
  （`:1228` 与 `:1949`），JS 语义下**后者静默覆盖前者**，故 `:1228` 是死代码，
  实际全局行为是 `:1949` 的 `0 → "0 B"` / 1 位小数。删除被覆盖者，保留共享工具区
  那份（`0 → "—"`、2 位小数），两端显示口径统一。
- **模板分层字号/字体要求不被执行**（用户报告）：三层原因叠加——① 用户把要求写在
  模板描述里，但该描述只存在于另一个数据根（`$DSH_HOME` 解析差异），活跃 store 中
  为空；② 技能声明 `detail` 返回偏好而实现未返回（见上）；③ 模板页面的文字规则
  全链路无人解析、排版合规也无任何机检。本版修掉 ②③，① 属数据层需用户在设置页
  补填。

## 5. 删除

- **死代码**（编译器旗标 `--noUnusedLocals --noUnusedParameters
  --allowUnreachableCode false` 判定 + 人工复核）：`src/routes.ts` 未使用的
  `HeaderValue` 类型；`scripts/smoke-plugin.mjs` 零调用的 `mockRes` 与 `byTag`；
  `render-architecture.mjs` 的 `polylinePath`、`render-sequence.mjs` 的
  `isFinitePoint` 两个未使用 import；`render_pptx.py` / `embed_animation.py` 的
  `import sys`；`html_capture.py` 未读取的 `channel` 绑定（改 `_channel`）。
- **死 CSS**：`.sp-root`（全仓无 `className: "sp-root"`）、`.sp-chip-row`、
  `.sp-chip`（实际渲染的是 `.sp-quick-chip`）三条零引用规则。

## 6. 兼容性与升级说明

- **升级方式**：替换包体即可，无迁移步骤。`lib/**` 为编译产物，随包发布。
- **peer 范围不变**：仍为 `>=0.1.0-rc.5 <1.0.0`，覆盖 `0.1.0-rc.5` → `0.2.1-alpha.2`
  全区间；上游兼容门 `plugin-compatibility.ts` 在 alpha.1→alpha.2 间 blob 级未变。
- **新增输出字段向后兼容**：`ppts_templates` 的 `constraints` 与 `detail.prefs` 均为
  新增字段，旧消费方忽略即可。
- **UI 宽度口径变化**：面板由「吃满宿主列」回到「限宽 960px 居中」——若你已在
  自定义样式里针对满宽做过适配，本版需重新对照。
- **⚠️ 数据层需要用户操作**：若你的模板描述/风格备注填写时所在宿主与当前宿主
  不是同一个 `$DSH_HOME`（例如在 KCoder 桌面端填、在 DSH Web 用），约束不会自动
  迁移。请在当前宿主的 Web 设置页「演示文稿」里重新填写模板描述与风格备注，
  `constraints` 才会出现在 `ppts_templates` 的返回中。
