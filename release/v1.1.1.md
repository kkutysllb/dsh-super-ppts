## 新增

### 混合交付：HTML 动画嵌入 PPTX（显式声明才启用）

插件双交付形态融合第一步：ppts-html 技能线（flowchart / arch-diagram /
ppt-animation 等 8 形态）生产的动画 HTML，可作为素材捕获后嵌入 PPTX。
**触发硬规则：Brief 明确出现「嵌入动画 / 动图 / GIF」等表述才启用；
内容「适合动画」不构成触发条件，默认仍为纯静态 PPTX。**

- `skills/ppts-pptx/scripts/html_capture.py`：动画 HTML → 快照 PNG /
  动图 GIF。playwright 帧捕获（chromium 缺失时依次回退系统 Chrome/Edge），
  ffmpeg 调色板两帧法合成 GIF（palettegen/paletteuse，bayer 抖动）；
  产物含快照、GIF 首帧海报、动图三件；超 3MB 软预算打 WARN。
- `skills/ppts-pptx/scripts/embed_animation.py`：把捕获产物嵌入 PPTX 指定页。
  语义 = **GIF 优先**（放映自动循环）→ **快照兜底**（无 GIF 嵌静态帧）→
  **超链接常挂**（图片单击打开随附 HTML 原件，完整交互在浏览器，
  不伪嵌入 PPTX）。盒内 fit-contain 等比缩放，可选 `--box`/`--note`，
  默认写新文件不覆盖构建产物。
- `compiler/build_pptx.py --check`（即 ppts_check 工具）增补媒体链探测：
  ffmpeg / playwright / 浏览器三项，全 WARN 语义——不阻断纯 PPTX 生成，
  只提示动画捕获链可用性。
- `skills/ppts-pptx/SKILL.md` 新增「混合交付」专章：触发硬规则、五步工作流
  （素材 → 捕获 → 嵌入 → 验收 → 双文件交付）、体积纪律（GIF ≤ 3MB 与降参顺序）、
  能力边界如实告知（GIF 不可暂停；交互只在随附 HTML；打印/PDF 为静态首帧；
  Phase 2 mp4 / Phase 3 原生 p:timing 为规划项）。
- 冒烟新增 2 项嵌入测试（真跑 python：空 deck → GIF/快照嵌入 → 解包断言
  media 部件与 External 超链接 rel）；python-pptx 不可用时自动 SKIP 不计失败。

### 设置页导航图标语义化（Web GUI）

- 宿主 0.1.x 的 `settings.section` 契约只投影 id/order/label，壳层对外部
  插件分区一律渲染通用 ⚙️。client 新增 `registerSettingsNavIcon()`：按本地化
  文案标记本插件导航行（`data-dsh-super-ppts-settings-nav`），CSS 注入
  Lucide「presentation」（幕布+支架）字形以 currentColor mask 替换齿轮，
  跟随导航 hover/active 配色；MutationObserver 跟随语言切换，disposer 清标记，
  HMR/停用无残留。冒烟双源同构哨兵新增该标记不变量。

## 兼容性与升级说明

- 新脚本为独立可选链：不装 playwright/ffmpeg 时纯 PPTX 生成与渲染验收
  完全不受影响（--check 仅打 WARN）；需要动画捕获时
  `python3 -m pip install --user playwright` + `python3 -m playwright install
  chromium`（或直接用系统 Chrome）+ `brew install ffmpeg`。
- PPTX 内嵌 GIF 兼容 PowerPoint 2013+/WPS/Keynote 放映模式；PDF 导出与打印
  显示静态首帧（海报帧），属格式边界而非缺陷。
- 升级方式：KCoder 插件管理检测新版本后手动更新；或 npm 渠道按原方式安装。
- client 图标为 DOM 适配层实现，宿主未来若在 settings.section 契约中原生支持
  icon 字段，可平滑切换（适配层只作用于自己的导航行，无全局副作用）。
