# v1.4.5（2026-09-27）

## 1. 版本信息

- **版本号**：1.4.5（patch）
- **日期**：2026-09-27
- **tag**：`v1.4.5`
- **主题**：任务面板宽度吃满 + 滚动条隐藏样式 + 模板入口按钮暗色主题修复
- **发布渠道**：npm + GitHub

## 2. 新增

- 无（本版为实机反馈的样式修正批）。

## 3. 变更

- **面板宽度吃满宿主列**（实机反馈）：`.sp-panels` 去掉
  `max-width:960px; margin:0 auto` 限宽居中列，改为 `width:100%` 直接吃满
  宿主 main 列；自适应机制不变——内边距走百分比（`clamp(24px,4%,48px)`）、
  `container-type:inline-size` 让 `@container` 窄列重排跟着宿主列宽走
  （侧边栏打开 ≠ 视口变化）、挂载期 `ResizeObserver` 观察父容器尺寸自动避让。
- **滚动条改隐藏样式**（实机反馈）：保留面板自滚（`height:100% +
  overflow-y:auto` 与 `fitToParent` 兜底不动），但轨道不再出现——
  `scrollbar-width:none`（Firefox）+ `::-webkit-scrollbar{display:none}`
  （Chromium）；旧的「9px 细轨 + 2px 内缩 thumb + `scrollbar-gutter:stable`」
  配方（`--dsh-scrollbar-*` 变量）随版移除。
- `src/client/index.ts` 功能面注释同步新口径（类型参考，不参与构建）；
  冒烟对应断言由「细轨配方」改为「滚动条隐藏样式」（含旧变量反向断言）
  + 新增「宽度吃满宿主列」断言。

## 4. 修复

- **模板入口按钮暗色主题下露出浏览器默认灰底外观**：「跟随默认模板」入口
  （`sp-tpl-open`）此前只有一条 `align-self` 布局规则、无任何视觉样式，
  渲染成 UA 默认 button（灰底深字），暗色主题下突兀且不跟随。补齐面板
  outline 按钮配方：透明底 + `0.5px border-l3` 发丝线 + 主文本色，hover
  `interactive-bg-hover` 填充；展开态按已有 `aria-expanded="true"` 属性加
  `interactive-bg-active` 底色（选择器打开时入口有选中反馈）。颜色全走
  `--dsw-alias-*` 令牌，明暗自适应。

## 5. 删除

- 面板滚动条细轨配方相关声明：`--dsh-scrollbar-width:9px` /
  `--dsh-scrollbar-thumb-border:2px` / `scrollbar-gutter:stable`
  （仅 `.sp-panels` 一处消费，随本版隐藏样式口径移除）。

## 6. 兼容性与升级说明

- 无接口契约变更：host 侧工具、`/super-ppts/api/*` 数据面、任务面板逻辑、
  会话桥均原样；`peerDependencies` 范围不动（`>=0.1.0-rc.5 <0.2.0`）。
- 仅 `lib/client.js` 样式层改动，直接从 1.4.4 升级即可，无迁移步骤。
