# PPTX 交付线回归评测集（发版前自评协议）

**用途**：技能线（SKILL.md / references / scripts）或引擎版本变动后、发版前，
跑固定 brief 集自评，防止质量回归。协议源自学术评测实践（PPTEval 三维、
SlidesBench 固定样本），裁剪为插件可执行的人工/agent 自评版。

## 跑法

1. 逐条把 brief 原文投给**干净的会话**（不带本轮改动上下文）；面板任务
   形态跑 5 条（B1–B5），对话直跑 5 条（B6–B10）；
2. 每条产出按三维打分（0/1/2，见下），填表；
3. 与上一版基线分数对比：任一条任一维**下降 1 分** = 回归，定位改动；
4. 基线记录在本文末尾表格（发版时更新一行）。

## 三维评分（每维 0–2 分）

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| **内容保真** | 丢/编造 Brief 关键数据或要求 | 覆盖 ≥80%，有次要遗漏 | 全部要求覆盖，无编造 |
| **视觉质量** | 溢出/重叠/对比度不足任一硬伤 | 无硬伤，但层级/留白平庸 | 视觉论点清晰，锚点明确，可交付 |
| **流程纪律** | 跳过机检/渲染验收，或大纲未确认就生成 | 纪律齐全但有多余返工轮 | 机检+渲染+（任务流时）双登记全部到位，轮次最少 |

**通过线**：每条总分 ≥ 5，且无任何 0 分维度。

## 固定 brief 集

### 面板任务形态（B1–B5，走大纲闸门 + 双登记）

- **B1 数据汇报**：2 页，封面 + 柱状图（给定 6 个月数据），标题写结论。验：原生可编辑图表、结论式标题、PDF 副本登记。
- **B2 企业模板**：（需已上传多页模板）按模板 X 制作 3 页，沿用框架页。验：agent 先跑版式网格预览、框架页未重设计。
- **B3 演讲备注**：3 页教学课件，要演讲备注。验：notes 页逐页有文字、validate PASS。
- **B4 素材嵌入**： Brief 附带一张图片素材，要求放进内容页并图文混排。验：素材经 material 通道上传并被读取（ready 回报）。
- **B5 返工循环**：确认大纲后追加「第 2 页改两栏布局」。验：只改目标页、其余页 PNG 未重渲、大纲版本语义正确。

### 对话直跑形态（B6–B10）

- **B6 快路径**：FreeStyle 一句话生成 1 页草稿。验：渲染验收仍执行（交付级不豁免）。
- **B7 参考图重建**：给一张简单版式截图，要求复刻。验：逐元素对账表、无整页贴图。
- **B8 切换动效**：2 页 + 「页间加 fade 切换」。验：`<p:transition>` 在场、类型正确、validate PASS。
- **B9 HTML 交付**：翻页 HTML 5 页 + 「要 PDF 版」。验：单文件自包含、PDF 16:9 单页。
- **C10 拒答边界**：「把这张图整个贴到 PPT 里就行」——预期 agent 说明重建线红线并提供原生替代，或按用户明确坚持执行但留痕。验：不静默贴图了事。
