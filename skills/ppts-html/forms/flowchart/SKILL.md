# 流程原理图（flowchart）

生成**教育/科普类流程图与原理演示动画**：根据概念、流程或模型，产出单文件
HTML，用动画直观展示工作原理与数据流动。

> 遵守入口共享工作流与 [../../shared/design-tokens.md](../../shared/design-tokens.md)。

**与 arch-diagram 的区隔**：本形态偏教育/科普，面向视频演示，轻量化，
注重「好看 + 直观」；arch-diagram 偏工程/架构，面向技术文档，专业级，
注重「精确 + 可导出」。

## 支持的图表类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 流程图 | 步骤流程、决策分支、循环 | 攻击链、渗透流程、API 调用链 |
| 概念图 | 概念关系、知识结构、对比 | AI 模型对比、协议分层、架构分层 |
| 原理演示 | 模型/算法/协议的动态工作过程 | RNN 展开、LSTM 门控、TCP 握手 |
| 时序图 | 消息交互、请求响应、调用链 | 客户端-服务端交互、认证流程 |
| 对比图 | 多方案并排对比 | RNN vs LSTM、HTTP vs HTTPS |
| 时间线 | 事件发展、版本演进 | 技术演进史 |
| 系统概览 | 简化架构、模块关系 | 微服务拓扑、网络拓扑（简化版） |

**AI/ML 经典子集**（成片示例在 `assets/`）：MLP 前向传播（`MLP.html`）、
RNN 时间步展开（`RNN.html`）、LSTM 三门机制（`LSTM-Introduce.html`）、
GRU 简化门控（`GRU-Introduce.html`）、Word2Vec 词向量（`word2vec.html`）。

## Step 1 · 确定演示对象

从用户输入识别目标概念/流程/模型。不明确时问一句（附推荐）。
**信息充足直接生成。**

## Step 2 · 规划演示结构

按内容类型选择可视化方式：

- **流程演示**：节点 + 连线，流动箭头，逐步点亮；
- **原理演示**：分阶段动画（展开/门控/传播），每阶段配说明；
- **对比演示**：左右并排，同节奏对照动画；
- **时序演示**：双方泳道，消息沿箭头流动。

## Step 3 · 生成标准

- 默认暗色科技风（`#0d1117` 或 `#0a0a1a` 底）；节点圆形渐变填充；
  数据包/信号用小矩形或光点带发光尾迹；箭头动态流动虚线；
- 概念分层用语义色区分（同 shared tokens 语义色约定）；
- 单文件 HTML 内联 CSS/JS，600-1200 行；纯 CSS/SVG 图形；
- 支持自动播放 + 手动步进 + 重置按钮。

## Step 4 · 交互与验收

必含：播放/暂停、重置/重播、每步说明文字。可选：步进模式、速度控制、
hover 字段解释。

验收：浏览器打开 + 截图多时间点检查（`node ../video-shots/scripts/shot.js`）——
无重叠遮挡、动画中间态不穿帮、重置后状态干净、说明文字与动画同步。
