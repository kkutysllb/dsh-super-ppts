# dsh-super-ppts DSH 0.1.16 适配升级实施计划

**Goal:** 移除失效的 Agent 预设安装模式并清理残留；把工作台升级为带工作区选择的完整原生界面，经正式 API 把 Brief 填入当前会话输入框（用户确认后发送）。

**Architecture:** Host 侧删 `ensurePresetInstalled` 换成幂等的旧预设目录清理；Client 侧把手写 `lib/client.js` 的剪贴板桥升级为「工作区落点（`uiWorkspace.openWorkspace`）→ `conversation.input.for(actx).setDraft`」正式链路，剪贴板降级为 fallback。设置页不动。

**Tech Stack:** 零 npm 依赖 Cordis/DSH 插件；host=tsc 产物（`npm run build` 重建 `lib/index.js`），client=手写自注册 bundle（`lib/client.js`，与 `src/client/index.ts` 人工同构）；冒烟=node 零依赖脚本。

**规格：** `docs/specs/2026-09-15-dsh-0.1.16-upgrade-design.md`

已核实的宿主契约（0.1.6-alpha.1 构建，即用户所称 0.1.16-alpha.1）：
- `WorkspaceView = { workspaceId, path, title, sessionIds, createdAt, updatedAt }`；快照 `{ items, phase: 'pending'|'ready', state }`。
- root 面板组件经全局标准 props 拿 `useWorkspaces`，选择器用法 `useWorkspaces(s => s.items)`。
- `ctx.uiWorkspace.openWorkspace(wsId)`：`connectWorkspace` 复用空白会话或新建 → `openSession`（自动切回对话视图）。
- `sessions.scope(id)` → `actx.conversation.input.for(actx).setDraft(text)`；shell 按 session binding 构建，不依赖 composer 挂载。
